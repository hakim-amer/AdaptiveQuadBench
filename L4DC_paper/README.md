# ICON-MPC — L4DC 2026 submission

Overleaf: zip this folder and upload it as a new project (compiler: pdfLaTeX, main file `main.tex`).
Local build: `tectonic -X compile main.tex`.

- `main.tex`, `macros.tex`, `references.bib`, `l4dc2026.cls` (loads `jmlr`, included in TeX Live/Overleaf)
- `sections/` — 00_abstract … 08_conclusion, A_proofs, B_implementation, C_additional_results
- `figures/` — generated by `python -m icon_mpc.paper_figures` (plus TikZ `architecture.tex`)
- `tables/` — generated by the same script from `icon_mpc/results/*.csv`
- `template/` — original L4DC sample files
